    # 设计一套可读的主题

    这是一段正文，用来检查长时间阅读时的舒适度。主题需要兼顾 文字层级、链接辨识度和搜索高亮。

    好的配色不抢内容的注意力，但能让结构一眼可见。

    ## 内容元素

    行内代码 theme.css 应该清晰，但不应像按钮一样突出。

    // Theme preview const theme = { name: "Typedown", contrast: 4.8, apply: renderTheme } body { color: var(--editorColor); }
