## English

**In short: Caret does not collect, store or share any personal data.** There is no account, no telemetry, no analytics and no advertising.

### Your documents stay on your device
Everything you do in Caret happens on your computer: writing, opening and saving notes, and converting Word, Excel, PowerPoint, PDF and CSV files to Markdown. Caret never uploads your notes or documents anywhere.

### What Caret stores, and where
Your settings, recent files, favorites, templates and crash-recovery backups of unsaved notes are stored in Caret's own app-data folder on your device. Uninstalling Caret removes them. Your notes are saved only where you choose to save them.

### When Caret connects to the internet
Caret itself only goes online in these cases:

| When | What happens | Can you turn it off? |
| --- | --- | --- |
| **Update check**, about once a day: after a successful check, not again for 20 hours; a check that failed (for example offline) is tried again at the next start. In every version not installed from the Microsoft Store: the one downloaded from GitHub, or a package your organization deploys itself. Never in the Microsoft Store version. | Caret asks GitHub (`api.github.com`) for the latest version number. Like any web request, GitHub sees your IP address and that the request comes from Caret. No information about you or your notes is sent. See [GitHub's privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement). | Yes: Settings → About → *Check for updates automatically*. Organizations can also turn it off for everyone. |
| **Images and links in your notes.** | If a note shows an image from a website, the editor loads it from that website, as a browser would. Clicking a link opens it in your browser. | Don't use web images, or use local image files. |
| **Installing MarkItDown**, only if you ask for it. In versions not installed from the Microsoft Store, never in the Microsoft Store version. | Python's `pip` downloads MarkItDown from the Python Package Index (`pypi.org`). This is only needed for rare formats; Word, Excel, PowerPoint, PDF and CSV don't need it. | It only happens when you click *Install*. |

Spell checking uses the spell checker built into Windows, on your PC. Caret itself does not send your text anywhere.

### Microsoft Store
If you install Caret from the Microsoft Store, Microsoft processes data about the installation under its own [privacy statement](https://privacy.microsoft.com/privacystatement). As the publisher, we only see aggregated statistics (such as the number of installs) and anonymous crash reports that Microsoft provides. We never receive your name, email address or documents.

### Children
Caret is a general productivity tool and collects no data from anyone, including children.

### Changes and contact
If this policy changes, the new version will be published at this address with a new date. Questions: open an issue at <https://github.com/fegyenc/Caret/issues>.

## Français

**En bref : Caret ne collecte, ne conserve et ne partage aucune donnée personnelle.** Pas de compte, pas de télémétrie, pas de statistiques d'utilisation, pas de publicité.

### Vos documents restent sur votre appareil
Tout ce que vous faites dans Caret se passe sur votre ordinateur : rédiger, ouvrir et enregistrer des notes, ou convertir des fichiers Word, Excel, PowerPoint, PDF et CSV en Markdown. Caret n'envoie jamais vos notes ni vos documents en ligne.

### Ce que Caret conserve, et où
Vos paramètres, fichiers récents, favoris, modèles et les sauvegardes de récupération des notes non enregistrées sont conservés dans le dossier de données de Caret sur votre appareil. Ils sont supprimés lorsque vous désinstallez Caret. Vos notes sont enregistrées uniquement à l'emplacement que vous choisissez.

### Quand Caret se connecte à Internet
Caret ne se connecte à Internet que dans les cas suivants :

| Quand | Ce qui se passe | Pouvez-vous le désactiver ? |
| --- | --- | --- |
| **Recherche de mises à jour**, environ une fois par jour : après une recherche réussie, pas de nouvelle recherche pendant 20 heures ; une recherche qui a échoué (hors ligne, par exemple) est refaite au démarrage suivant. Dans toute version qui n'est pas installée depuis le Microsoft Store : celle téléchargée depuis GitHub, ou un paquet que votre organisation déploie elle-même. Jamais dans la version du Microsoft Store. | Caret demande à GitHub (`api.github.com`) le numéro de la dernière version. Comme pour toute requête web, GitHub voit votre adresse IP et le fait que la requête provient de Caret. Aucune information vous concernant ni aucune de vos notes n'est envoyée. Voir la [déclaration de confidentialité de GitHub](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement). | Oui : Paramètres → À propos → *Rechercher automatiquement les mises à jour*. Une organisation peut aussi la désactiver pour tous. |
| **Images et liens dans vos notes.** | Si une note affiche une image provenant d'un site web, l'éditeur la charge depuis ce site, comme le ferait un navigateur. Un clic sur un lien l'ouvre dans votre navigateur. | N'utilisez pas d'images web, ou utilisez des fichiers image locaux. |
| **Installation de MarkItDown**, uniquement si vous la demandez. Dans les versions qui ne sont pas installées depuis le Microsoft Store, jamais dans la version du Microsoft Store. | L'outil `pip` de Python télécharge MarkItDown depuis le Python Package Index (`pypi.org`). Il n'est nécessaire que pour des formats rares : Word, Excel, PowerPoint, PDF et CSV n'en ont pas besoin. | Cela n'a lieu que si vous cliquez sur *Installer*. |

La vérification orthographique utilise le correcteur orthographique intégré à Windows, sur votre PC. Caret n'envoie votre texte nulle part.

### Microsoft Store
Si vous installez Caret depuis le Microsoft Store, Microsoft traite les données liées à l'installation selon sa propre [déclaration de confidentialité](https://privacy.microsoft.com/fr-fr/privacystatement). En tant qu'éditeur, nous ne voyons que des statistiques agrégées (comme le nombre d'installations) et des rapports d'incident anonymes fournis par Microsoft. Nous ne recevons jamais votre nom, votre adresse e-mail ni vos documents.

### Enfants
Caret est un outil de productivité généraliste qui ne collecte aucune donnée, y compris auprès d'enfants.

### Modifications et contact
Si cette politique change, la nouvelle version sera publiée à cette adresse avec une nouvelle date. Pour toute question : ouvrez un ticket sur <https://github.com/fegyenc/Caret/issues>.

## Español

**En resumen: Caret no recopila, almacena ni comparte ningún dato personal.** No hay cuenta, ni telemetría, ni estadísticas de uso, ni publicidad.

### Tus documentos se quedan en tu dispositivo
Todo lo que haces en Caret ocurre en tu equipo: escribir, abrir y guardar notas, y convertir archivos de Word, Excel, PowerPoint, PDF y CSV a Markdown. Caret nunca sube tus notas ni tus documentos a ningún sitio.

### Qué guarda Caret y dónde
Tu configuración, archivos recientes, favoritos, plantillas y las copias de recuperación de notas sin guardar se almacenan en la carpeta de datos de Caret en tu dispositivo. Se eliminan al desinstalar Caret. Tus notas se guardan solo donde tú decides.

### Cuándo se conecta Caret a Internet
Caret solo se conecta a Internet en estos casos:

| Cuándo | Qué ocurre | ¿Se puede desactivar? |
| --- | --- | --- |
| **Búsqueda de actualizaciones**, aproximadamente una vez al día: tras una búsqueda correcta, no se repite durante 20 horas; si falla (por ejemplo, sin conexión), se vuelve a intentar en el siguiente inicio. En cualquier versión que no se haya instalado desde Microsoft Store: la descargada de GitHub o un paquete que tu organización distribuye por su cuenta. Nunca en la versión de Microsoft Store. | Caret pregunta a GitHub (`api.github.com`) cuál es el número de la última versión. Como en cualquier petición web, GitHub ve tu dirección IP y que la petición viene de Caret. No se envía nada sobre ti ni sobre tus notas. Consulta la [declaración de privacidad de GitHub](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement). | Sí: Configuración → Acerca de → *Buscar actualizaciones automáticamente*. Las organizaciones también pueden desactivarla para todos. |
| **Imágenes y vínculos en tus notas.** | Si una nota muestra una imagen de un sitio web, el editor la carga desde ese sitio, como haría un navegador. Al hacer clic en un vínculo, se abre en tu navegador. | No uses imágenes web, o usa archivos de imagen locales. |
| **Instalación de MarkItDown**, solo si la pides. En las versiones que no se instalan desde Microsoft Store, nunca en la versión de Microsoft Store. | La herramienta `pip` de Python descarga MarkItDown del Python Package Index (`pypi.org`). Solo hace falta para formatos poco comunes: Word, Excel, PowerPoint, PDF y CSV no la necesitan. | Solo ocurre si haces clic en *Instalar*. |

La revisión ortográfica usa el corrector ortográfico integrado en Windows, en tu equipo. Caret no envía tu texto a ningún sitio.

### Microsoft Store
Si instalas Caret desde Microsoft Store, Microsoft trata los datos de la instalación según su propia [declaración de privacidad](https://privacy.microsoft.com/es-es/privacystatement). Como editores, solo vemos estadísticas agregadas (como el número de instalaciones) e informes de errores anónimos que proporciona Microsoft. Nunca recibimos tu nombre, tu correo electrónico ni tus documentos.

### Menores
Caret es una herramienta de productividad general que no recopila datos de nadie, tampoco de menores.

### Cambios y contacto
Si esta política cambia, la nueva versión se publicará en esta dirección con una nueva fecha. Para cualquier pregunta, abre una incidencia en <https://github.com/fegyenc/Caret/issues>.

## Polski

**W skrócie: Caret nie zbiera, nie przechowuje ani nie udostępnia żadnych danych osobowych.** Nie ma konta, telemetrii, statystyk użycia ani reklam.

### Twoje dokumenty zostają na Twoim urządzeniu
Wszystko, co robisz w programie Caret, dzieje się na Twoim komputerze: pisanie, otwieranie i zapisywanie notatek oraz konwertowanie plików Word, Excel, PowerPoint, PDF i CSV na Markdown. Caret nigdy nie wysyła Twoich notatek ani dokumentów nigdzie przez internet.

### Co Caret przechowuje i gdzie
Twoje ustawienia, ostatnie pliki, ulubione, szablony i kopie zapasowe niezapisanych notatek służące do odzyskiwania po awarii są przechowywane w folderze danych programu Caret na Twoim urządzeniu. Odinstalowanie programu Caret usuwa je. Twoje notatki są zapisywane wyłącznie tam, gdzie zdecydujesz się je zapisać.

### Kiedy Caret łączy się z internetem
Sam Caret łączy się z internetem tylko w następujących przypadkach:

| Kiedy | Co się dzieje | Czy można to wyłączyć? |
| --- | --- | --- |
| **Sprawdzanie aktualizacji**, mniej więcej raz dziennie: po udanym sprawdzeniu następne nie odbywa się przez 20 godzin; sprawdzenie, które się nie powiodło (na przykład bez połączenia), jest ponawiane przy następnym uruchomieniu. W każdej wersji niezainstalowanej ze sklepu Microsoft Store: pobranej z serwisu GitHub lub w pakiecie wdrażanym przez Twoją organizację. Nigdy w wersji ze sklepu Microsoft Store. | Caret pyta serwis GitHub (`api.github.com`) o numer najnowszej wersji. Jak każde żądanie internetowe, GitHub widzi Twój adres IP i to, że żądanie pochodzi z programu Caret. Nie są wysyłane żadne informacje o Tobie ani o Twoich notatkach. Zobacz [oświadczenie o ochronie prywatności serwisu GitHub](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement). | Tak: Ustawienia → Informacje → *Automatycznie sprawdzaj aktualizacje*. Organizacje mogą też wyłączyć to dla wszystkich. |
| **Obrazy i łącza w Twoich notatkach.** | Jeśli notatka pokazuje obraz ze strony internetowej, edytor ładuje go z tej strony, tak jak zrobiłaby to przeglądarka. Kliknięcie łącza otwiera je w przeglądarce. | Nie używaj obrazów z internetu albo używaj lokalnych plików obrazów. |
| **Instalowanie narzędzia MarkItDown**, tylko na Twoje żądanie. W wersjach niezainstalowanych ze sklepu Microsoft Store, nigdy w wersji ze sklepu Microsoft Store. | Polecenie `pip` środowiska Python pobiera narzędzie MarkItDown z indeksu pakietów Python (`pypi.org`). Jest ono potrzebne tylko dla rzadkich formatów; Word, Excel, PowerPoint, PDF i CSV go nie potrzebują. | Dzieje się to tylko po kliknięciu przycisku *Zainstaluj*. |

Sprawdzanie pisowni korzysta z narzędzia do sprawdzania pisowni wbudowanego w system Windows, na Twoim komputerze. Sam Caret nie wysyła Twojego tekstu nigdzie.

### Microsoft Store
Jeśli zainstalujesz program Caret ze sklepu Microsoft Store, firma Microsoft przetwarza dane dotyczące instalacji zgodnie z własnym [oświadczeniem o ochronie prywatności](https://privacy.microsoft.com/pl-pl/privacystatement). Jako wydawca widzimy tylko zbiorcze statystyki (takie jak liczba instalacji) i anonimowe raporty o awariach udostępniane przez firmę Microsoft. Nigdy nie otrzymujemy Twojego imienia i nazwiska, adresu e-mail ani dokumentów.

### Dzieci
Caret jest ogólnym narzędziem do zwiększania produktywności i nie zbiera danych od nikogo, także od dzieci.

### Zmiany i kontakt
Jeśli ta polityka ulegnie zmianie, nowa wersja zostanie opublikowana pod tym adresem z nową datą. Pytania: zgłoś problem pod adresem <https://github.com/fegyenc/Caret/issues>.
